# Fish pictures for the catch card — ChatGPT commands

When you land a fish, the game shows its picture from `assets/fish/<file name>`.
Until a picture exists, the card shows the fish's name and the file it's waiting for.

## How to use

1. Open ChatGPT and start a **new chat for each fish** (keeps the style clean).
2. Copy **one whole command** below (everything in the grey box) and paste it in.
3. Download the image, save it as a **PNG** with the exact file name shown.
4. Put it in the game's `assets/fish/` folder.
5. Double-click **`Optimize Fish Images.bat`** in the game folder. It turns each 2–3 MB PNG into an
   ~50–80 KB `.webp` (800 px wide, transparent background kept) so the catch card loads fast on
   phones. The game uses the `.webp`; the PNG stays as your original. Run it again whenever you add
   or replace a picture.
6. Refresh the game.

If ChatGPT gives a background, reply: `Remove the background and make it transparent PNG, same fish.`
If the fish faces the wrong way, reply: `Flip it so the head faces right.`
